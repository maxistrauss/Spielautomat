# Slot Machine (Spielautomat)

A small slot machine game with a graphical user interface – one of my first Java projects (2018).

![Slot machine](src/Automat.png)

## Features

- Swing GUI with three spinning reels and animated spins (timer-based)
- Random symbols and win evaluation
- Credit balance and a jackpot that is saved between sessions (`jackpot.txt`)

## Run

Open the project in IntelliJ IDEA and run `src/Main.java` (Java 8+).
